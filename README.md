# Ещё один билд

Пиксельный симулятор разработки игр для **Unity 6.6 (6000.6.7f1)** на Linux. Интерактивный офис, собственные проекты, рынок и финансовые последствия решений. По подаче и набору решений ориентируется на Game Dev Story / Game Dev Tycoon, с оригинальной графикой и собственной моделью.

![Офис](Assets/OneMoreBuild/Resources/Art/room.png)

## Запуск

1. **Code → Download ZIP** и распаковать архив либо `git clone https://github.com/Xelyphor/devgame.git`.
2. **Unity Hub → Projects → Add project from disk**: выбрать корень `devgame-main`/`devgame`, где вместе лежат Assets, Packages и ProjectSettings.
3. Открыть редактором **6000.6.7f1**, дождаться импорта.
4. Открыть `Assets/OneMoreBuild/Scenes/Studio.unity` и нажать **Play**. Вкладка Game: **1280×720** или **1920×1080**.

Сцена до Play пустая намеренно. Камера, офис, персонаж и интерфейс создаются автоматически. Ручная привязка объектов, платные ресурсы, URP и дополнительные платформенные модули для запуска в редакторе не нужны.

**Статус проверки:** 173 утверждения в C#-тестах экономики/сохранений и 133 статические проверки. Редактор Unity в облаке отсутствует: импорт, запуск, новые окна и финальная сборка в 6000.6.7f1 здесь не проверены. [Подробности и чеклист](Docs/VALIDATION.md).

## Что нового в экономике

- Выпуск — отдельное событие: четыре оценки прессы, разбор качества и рыночных факторов.
- Выбор платформы **ПК/телефон**, аудитории, цены **5/10/18**, рекламы и продолжения успешной игры.
- Продажи **по неделям**, график и таблица фактических копий. Первой мгновенной выплаты нет: первый отчёт через 7 игровых дней.
- **Возвраты покупателей, комиссия магазина 30%, бюджет, доход и прибыль** каждого проекта.
- Ежедневные расходы студии и оборудования. При нуле денег счета превращаются в долг; доход сначала погашает его.
- Заказы по телефону требуют времени и занимают разработчика. Это способ восстановиться, а не моментальная бесплатная выплата.
- Тренды, конкурентная неделя, соответствие жанра аудитории/платформе, усталость от повторяющихся идей.
- Патч после выпуска стоит ресурсов и времени, уменьшает будущие возвраты; старую статистику не переписывает.
- Исследования движка, графики и аналитики за деньги и опыт.

Полные правила, формулы и ограничения: [Docs/ECONOMY.md](Docs/ECONOMY.md).

## Управление офисом

Нажимай на предметы: персонаж подойдёт и откроет соответствующее окно.

| Предмет | Действие |
| --- | --- |
| Компьютер | Новый проект, направление работы и разовые задания |
| Диван | Отдых; закрой окно, чтобы время продолжилось |
| Телефон слева от компьютера | Заказ: 20 энергии, 48 часов, 90 монет после выполнения |
| Доска на стене | Каталог релизов, отчёты и поддержка патчами |
| Коробка у входа | Шесть улучшений офиса |

В **Меню** находятся финансы, рынок, исследования, помощь, звук и сохранение. **Пробел** — пауза; **Esc** — закрыть окно; **Ⅱ/1×/3×** — скорость. Окна и короткое перемещение персонажа останавливают симуляцию. **Один игровой час = одна реальная секунда на 1×**.

## Первая игра

1. Нажми на компьютер. Назови проект, выбери жанр, тему и размер.
2. На втором экране выбери платформу, аудиторию, цену и рекламу. Не трать весь баланс: студия платит за каждый день. На старте 400 монет, мини-проект стоит 90 без рекламы.
3. Меняй направление работы: жанры требуют разных пропорций кода, графики и полировки. Подсказки — в «Рынке».
4. При энергии ниже 20% отдохни. Выполни при необходимости задания: поиск бага, плейтест и рывок. Они доступны по разу на проект.
5. Релиз разрешён от 60%, но незавершённость и баги снижают оценку и увеличивают возвраты. На 100% можно продолжать доводку — время и счета при этом идут.
6. В каталоге нажми «Отчёт»: обзор, продажи, разбор. Продажи затухают в течение шести недель. График показывает состоявшиеся продажи, а не гарантированный прогноз.
7. Рекламируй подходящий продукт, пробуй новые сочетания, изучай технологии. При долге возьми заказ; собственная разработка на время заказа остановится.

Цель главы остаётся прежней: три релиза и рабочая станция, затем можно продолжать. Длительность и баланс новой экономики ещё требуют живого плейтеста.

## Сохранения и обновление

Автосохранение каждые 20 реальных секунд, при значимых действиях и выходе. Файл `studio-save.dat` находится в `Application.persistentDataPath`: на Linux обычно `~/.config/unity3d/Xelyphor/One More Build/`. Открыть папку: **Ещё один билд → Показать папку сохранений**.

Формат состояния — **v2**, с контрольной суммой, временным файлом и резервной копией `.bak`. Сохраняются выплаты по неделям, задолженность, заказы, патчи, проект, задачи и генератор случайности. Офлайн-дохода нет.

Старое сохранение v1 преобразуется автоматически с сохранением денег, улучшений и активного проекта. Старые релизы архивируются и получают только оставшуюся выплату по прежним правилам; недоступная статистика для них не выдумывается. Перед первым обновлением полезно сохранить копию папки сохранений. Для новой игры перемести основной файл и `.bak` из этой папки при закрытой игре.

## Разработка и проверки

- `GameModel.cs` — состояние и основная симуляция.
- `Market.cs` — экономика, недельные продажи, миграция, исследования и патчи.
- `GameClock.cs` — время, пауза и ускорение.
- `SaveRepository.cs` — сохранение, контрольная сумма, восстановление.
- `StudioApp.cs`, `OfficeView.cs`, `BusinessView.cs` — интерфейс и запуск.
- `Editor/ProjectTools.cs` — открыть сцену, проверить ресурсы, собрать Linux.
- `Resources` — оригинальные пиксельные текстуры и встроенный DejaVu Sans с кириллицей и лицензией.

```bash
dotnet run --project Tests/SimulationTests.csproj
# Необязательные статические проверки: Python + Pillow + fonttools
python3 Tools/validate_project.py
```

.NET 8 нужен только для независимых тестов. Пакетный импорт при установленном Unity:

```bash
/path/to/Unity -batchmode -nographics -projectPath "$PWD" \
  -executeMethod OneMoreBuild.Editor.ProjectTools.ValidateProject \
  -quit -logFile unity-validation.log
```

Сборка: **Ещё один билд → Собрать для Linux**. Используется Mono; при выборе IL2CPP понадобится соответствующий модуль и системный компилятор. Сборка в этой среде не выполнялась.

Графика воспроизводится `Tools/draw_art.py` (создаёт персонажа и обновлённый офис), настройки контента находятся в Catalog и Market. Платных ассетов и внешних сетевых сервисов игра не использует.
